# comptimize-site

The public website for [comptimize.com](https://comptimize.com), served by GitHub Pages from the `main` branch.

- `index.html`: the whole site, one self-contained page.
- `sample-audit-report.pdf`: the sample report linked from the page (fictional client, made-up numbers).
- `CNAME`: tells GitHub Pages to serve the site at comptimize.com.

The source of truth for `index.html` is `site/index.html` in the private Comptimize repo. To update the live site, copy the new file here and commit it to `main`.
